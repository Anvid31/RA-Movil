# RA-Movil — Augmented Reality

Dual-platform augmented reality project: an **Angular** web frontend and a **Flutter** mobile app, exploring AR experiences across web and native mobile.

## Structure

```
├── Frontend/   # Angular web app with AR integration
└── Mobile/     # Flutter mobile app
```

## Stack

- **Web:** Angular, TypeScript, Tailwind CSS
- **Mobile:** Flutter / Dart
- **Deployment:** Docker (Frontend)

## Getting started

```bash
# Web frontend
cd Frontend && npm install && ng serve

# Mobile app
cd Mobile && flutter pub get && flutter run
```
